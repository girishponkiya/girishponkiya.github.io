# Girishkumar Ponkiya — Personal Website & Portfolio

Personal profile website of **Girishkumar Ponkiya** (Vice President & Data Scientist at ISS STOXX, Ph.D. in Natural Language Processing from IIT Bombay).

Hosted live on GitHub Pages at [www.girishp.in](https://www.girishp.in).

## Tech Stack & Architecture

- **Core**: Vanilla HTML5, modern CSS3 (Custom Properties, Liquid Glass SVG filters, glassmorphism), Vanilla JavaScript.
- **Typography**: Inter (via Google Fonts).
- **Icons**: Font Awesome 6.
- **Design System**: Liquid Glass iOS-inspired card stack with automatic dark/light theme switching and clear/tinted mode toggles.
- **Deployment**: Hosted via GitHub Pages with custom domain CNAME (`www.girishp.in`).

## Local Development

No build pipeline or npm dependencies required. To run locally:

```bash
# Python built-in HTTP server
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

## Repository Notes

- **Image Assets**: `images/background_bold.webp` and `images/profile.webp` are the optimized WebP images served on the site. Original `.jpg`/`.jpeg` source files are preserved in the repository for reference.
- **Prototypes**: Layout and theme prototypes are stored under `/themes/`.
